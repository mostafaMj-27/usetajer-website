## 🔒 Google OAuth & Privacy Compliance

الموقع معتمد كمرجع رسمي لتطبيق تاجر في منصة Google Cloud Console / Google Auth Platform:
- **نطاق الصلاحية الوحيد المستخدم لـ Google Drive:**
  `https://www.googleapis.com/auth/drive.file`
- يعمل التطبيق بأسلوب **Offline-First**، وتُشفر النسخ الاحتياطية محلياً بخوارزمية **AES-256-GCM** قبل رفعها إلى Google Drive.
